# Spring AI Examples

This is a fork of the original [spring-projects/spring-ai-examples](https://github.com/spring-projects/spring-ai-examples) repository.

A collection of Spring AI examples demonstrating various AI integration patterns and use cases, including agentic workflow patterns, Model Context Protocol (MCP) clients/servers, Kotlin examples, and function-calling/prompt-engineering demos.

See the module-specific `README.md` files throughout the repository for details on each example.
